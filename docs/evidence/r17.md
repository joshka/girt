## Contract and Public API

The new `girt::ignore` module exports `Ignore`, `Source`, `Case`, `Limits`, `Match` and `Error`.
`Ignore::new` chooses comparison and budgets; `add` compiles caller-supplied source bytes
atomically; `check` returns the decisive rule or no match. Provenance identifies the successful
source insertion, physical line and matched prefix length. A negative rule is distinguishable from
no rule; an excluded ancestor identifies its own rule rather than a child's inapplicable negation.

Sources rank from global excludes to info/exclude, directory files and explicit command rules.
Deeper directory files win; later additions at equal scope and later lines win. Sources may be added
out of traversal order. Prefixes require component boundaries. Every ancestor is checked before the
final path, so a rule inside an excluded directory cannot re-include its descendants. Re-including
that directory permits subsequent child decisions.

Inputs and paths preserve bytes without Unicode decoding. Paths must be relative, nonempty and
NUL-free, with no empty, dot or parent components; root source prefixes alone may be empty. No
trailing query slash is accepted: directory classification is explicit. Backslash remains an
ordinary path byte. Case is explicitly sensitive or ASCII-insensitive, including source prefixes;
Unicode case and normalization are not inferred from the host. POSIX character classes use ASCII
membership. The grammar follows the [Git ignore specification](https://git-scm.com/docs/gitignore)
and independently generated executable observations: comments, escaped markers/trailing spaces,
negation, slash anchoring, directory-only rules, `?`, `*`, recursive `**`, ranges and named classes.
LF/CRLF, an initial UTF-8 BOM and line truncation at NUL match the observed reader. Invalid classes,
unknown named classes and terminal escapes never match. Escaping the separator after recursive stars
keeps its mandatory slash while allowing deeper matching.

Callers load the resolved `core.excludesFile`, common-directory `info/exclude` and encountered
`.gitignore` content. Home/default/config selection, missing-file policy and loading errors remain
explicit caller responsibilities. Do not follow worktree `.gitignore` symlinks. The matcher never
opens files, discovers sources, reads an index or mutates a repository. Traversal, symlink handling,
tracked-file selection and filesystem consistency remain caller-owned. This is a reusable matcher,
not automatic repository status integration. The runnable `examples/ignore_batch.rs` demonstrates a
bounded loader and a NUL-delimited file-query adapter.

The private `ignore::pattern` owns compiled glob tokens and `ignore::rules` owns source precedence
and ancestor decisions. Existing config-condition matching is unchanged: its per-query parser and
caller-specific semantics do not provide the compiled ignore concept needed here. No dependency is
added, and no upstream Git, gix or libgit2 implementation or test source was used.

## Resource and Failure Contract

Default budgets are 8 MiB aggregate source/prefix bytes, 4096 sources, 100,000 rules, 4096-byte
physical lines and paths, and 100 million conservative work units per query. Callers may choose
other budgets. Matching work is shared across sources, rules and ancestors; exhaustion is an error,
never a partial decision or a negative match. Repeating a query receives a fresh budget. Failed
additions retain neither partial rules nor consumed source indices.

Compilation is linear in input length with bounded byte-class expansion. Source insertion sorts
source precedence; queries scan applicable sources in reverse precedence. Literal-prefix rejection
avoids allocating DP rows for most unrelated globs. Remaining glob matching uses two reusable rows,
with O(tokens × path bytes) time and O(path bytes) scratch; it has no recursive backtracking. Input
and retained set budgets also bound invalid patterns. Compiled tokens can use up to 40 bytes per
pattern byte, plus vector, rule and source overhead. Limits do not promise exact RSS or recoverable
allocation failure. There is no cancellation API; a query's work budget bounds synchronous work.
Callers needing scheduling responsiveness should choose suitable budgets and execution boundaries.

Race/write/fault-publication cases are inapplicable to this pure owned-data API. Loading failures
belong to the caller. Unit cases exercise zero/exhausted work, cumulative ancestor work, every
storage/input limit, invalid paths and atomic failed additions. The adversarial star-chain query
returns a work error reproducibly. A separate 100,000-pattern process probe compiles a
2,177,780-byte original source and queries an unmatched path. Local peak child RSS is 81,231,872
bytes, including startup, loader content, compiled rules and the query; it is not retained-set
allocation. The matcher opens no descriptors and retains no file handles. Native Windows RSS is not
supplied.

## Compatibility and Consumer Evidence

`tests/ignore.rs` has 116 SHA-1/SHA-256 cases using original repository fixtures and Git's
`check-ignore --no-index --verbose -z --stdin`. Tests distinguish actual directory queries from
names with an appended slash: `a/**` does not exclude directory `a`, while `a/` is a different CLI
input. Coverage includes hierarchy, all source levels below command rules, case, raw non-UTF-8
names, named/range/malformed classes, escapes, BOM/CRLF/NUL, negation and ignored parents. Unit
coverage supplies command-rule precedence and source provenance. A tracked-file fixture verifies why
callers must retain index ownership: ordinary `check-ignore` omits the tracked path while
`--no-index` and the matcher classify it by rules.

`tests/fixtures/ignore/observe.py` generates 415 original patterns, including deterministic
malformed inputs with seed 170010, and 147 byte paths. It compares exact NUL-delimited ignored-file
output from Git and the batch adapter. All 61,005 path/pattern observations agree locally. Raw
patterns, paths, outputs, versions and seed are retained; this finite corpus is not exhaustive
grammar parity.

The unchanged jj consumer at `/Users/joshka/local/jj/work/default/lib/src/gitignore.rs` uses
case-sensitive matching and caller recursion. `cli/src/cli_util.rs` resolves global paths and layers
info/exclude before per-directory content. No jj source was changed. The original
`tests/fixtures/ignore/jj-observe.py` runs installed jj 0.45.1 on disposable both-format
repositories. Its file lists preserve global/info/directory precedence, parent pruning and already
tracked ignored files. These observations and the new public-API fixtures establish the scoped
replacement requirements; final removal of gix-ignore and full consumer integration remain R35.

## Local Validation and Measurements

Scoped checks pass 41 units, 116 integration cases, 22 crate doctests, all-feature/all-target
Clippy, nightly formatting, rumdl, docs.rs and warning-denying private Rustdoc. Unchanged repository
suites reuse R40 and earlier evidence as authorized. Browser security policy blocks local-file
Rustdoc viewing; no workaround was attempted and no rendered-layout claim is made.

`cargo build --release --example ignore_batch` followed by `cargo bench --bench ignore -- --noplot`
runs Criterion with 20 samples, a one-second warmup and a two-second requested measurement window
per workload. Original fixtures contain 201 or 2001 rules and 1000 paths: literal generated files,
recursive cache patterns, unmatched source paths and an explicit negation. Each setup checks
byte-identical results from Git, the adapter and the library. Both formats are measured, although
this API does not parse object IDs. Fixture creation is outside timing. Release defaults are used on
macOS 26.6.2 arm64 with Rust 1.98.1 and Git 2.55.0.

The preloaded library measurement includes checks and output allocation. Process measurements also
include startup, pipes, loading and output; Git additionally discovers its repository/configuration.
Both use warm filesystem caches and fresh processes; the library reuses compiled rules. No cold
cache, persistent Git process or all-function parity is claimed. Concurrent local tooling can affect
these measurements. Values below are Criterion point estimates and confidence intervals; raw samples
and outlier reports are retained.
