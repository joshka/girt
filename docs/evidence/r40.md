## Acceptance Contract

Provide bounded imported history and conservative recoverable roots in both hash formats through
files and reftable reference handles. Preserve files bytes and decoded binary fields independently
of interpreted dates and canonical append construction. Include unsigned binary timestamps beyond
`i64::MAX`. Return inspectable incomplete, corrupt, limited, cancelled and I/O outcomes; an unread
or uninterpretable portion must never imply that recovered roots are exhaustive. R31 owns log
discovery across deleted names/worktrees, retention policy and repository-wide GC coordination;
R32/R33 own maintenance execution.

Reproduce the original R11/R14 CR, NUL, short/suffixed timezone, overflow timestamp, unterminated
tail and 1 MiB message cases with explicitly named Git operations and symbolic/detached HEAD
controls. Exercise unusual preexisting append tails while preserving canonical write validation.
Validate large-log budgets, fault recovery, worktree routing, binary stack limits and native
execution on Linux, macOS and Windows. Retain measurements, exact revisions and logs without
claiming universal Git grammar, complete consumer parity or expiry policy.
