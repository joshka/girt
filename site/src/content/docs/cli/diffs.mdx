`diff A B` compares two commit or tree revisions. `--names` is the default; `--renames` detects
renames, `--copies` also considers copies from modified files, and `--patch` writes a unified diff.
Run `girt help diff` for the supported combinations.

:::caution[Experimental CLI]
The girt CLI is not a replacement for Git. It exercises the library's Git operations and provides a
testing surface for performance and byte-for-byte comparisons with Git. Command names and parameters
may change; the library is the core deliverable.
:::

## Find changed paths

<CommandExample
  command="girt diff HEAD~1 HEAD"
  api="Objects::compare_trees"
  apiPath="objects/struct.Objects.html#method.compare_trees"
  git="git diff-tree --no-commit-id -r --name-status HEAD~1 HEAD"
  note="Use --patch to see changed lines, or --renames to detect renamed paths."
>

Use the repository from [Getting started with the CLI](/girt/cli/getting-started/).

```text
$ girt diff HEAD~1 HEAD
M notes.txt
```

`M` identifies a modified file. The old revision is the parent of HEAD; the new revision is HEAD.
Add `--patch` to see the changed lines, or `--renames` to distinguish renamed paths from separate
additions and deletions.

The corresponding Git operations are `git diff-tree --no-commit-id -r --name-status HEAD~1 HEAD` for
names, its `-M` option for rename detection, and `git diff HEAD~1 HEAD` for patches.

</CommandExample>

## Library API and limits

Plain comparisons use
[Objects::compare_trees](https://docs.rs/girt/latest/girt/objects/struct.Objects.html#method.compare_trees).
Rename and copy detection use
[Objects::diff_trees_with](https://docs.rs/girt/latest/girt/objects/struct.Objects.html#method.diff_trees_with)
with [rewrites::Options](https://docs.rs/girt/latest/girt/rewrites/struct.Options.html). Patch
output uses
[Objects::write_patch_with](https://docs.rs/girt/latest/girt/objects/struct.Objects.html#method.write_patch_with)
and repository diff attributes.

Patches use Myers diff, so ambiguous hunks can align differently from Git. A warning reports when
limits skip exhaustive rename detection; the remaining comparison still has useful path changes. See
[Diffs and renames](/girt/guides/diffs-and-renames/) for attribute policy, similarity and limits.
